# ন্যায্য ভাড়া (Nayyo Bhara)
Live Server : https://dhakanayyavara-config.vercel.app/

A web-based bus fare information system for Dhaka, Bangladesh.

## About
ন্যায্য ভাড়া is a web application that helps passengers find bus routes and calculate estimated fares between two bus stops in Dhaka.

## Features
- Search bus fare by starting and ending stops.
- View available buses on selected routes.
- Display bus route information.
- Calculate estimated bus fares.
- View bus stops and route details.
- Simple and user-friendly interface.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- Tailwind CSS
- SQLite

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Alokkumarpaul106/Dhaka_nayya_vara.git
```

2. Go to the project directory:

```bash
cd Nayyo_Bhara
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the environment:

```bash
venv\Scripts\activate
```

5. Install requirements:

```bash
pip install -r requirements.txt
```

6. Run migrations:

```bash
python manage.py migrate
```

7. Start the development server:

```bash
python manage.py runserver
```

Open in browser: `http://127.0.0.1:8000/`
